# 行为评测

`tests/` 检查脚本算得对不对；这里检查助手在对话里是否遵守约定，例如计划不算已吃、购物车不算库存、忌口优先于达标。

`evals.json` 每条含 `prompt`（模拟的用户请求与状态）和 `expectations`（逐条判定的期望）。用法：

1. 在支持 skill 的 AI 工具中，分别在安装与不安装（或旧版本）本 skill 的环境下运行每条 prompt。
2. 按 `expectations` 逐条判定通过与否，记录通过率。
3. 改规则时新增或调整对应用例；发版说明里写明通过率与已知失败项。

用例全部是虚构数据，不使用任何人的真实库存或健康资料。也可以配合 skill-creator 的评测流程运行。
