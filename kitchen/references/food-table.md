# 食材表与计数口径 · v5.4

19 个类别名与 SKILL.md 一致。**这是饮食规划清单，覆盖度不是炎症检测、完整营养评估或临床处方。**「每日必有」沿用产品名称，表示默认规划频率，不表示人人每天必须吃到每一类。过敏、耐受、个人需求优先。

以下列出默认频次；用户可通过个人设置调整为每天或每周次数，或不设要求。类别和计数权重保持不变。其他蛋白四类可设合计频次（同餐最多 1 次），默认不设；中性食物不设频次。默认每天安排蛋白质来源，并保留高脂鱼及豆类/豆制品的有效计划频次，其他蛋白不应挤占它们；过敏、忌口优先并安排替代。

## 每日必有 8 类

豆类与豆制品是**一个合并目标**，整豆优先是选材建议，不额外设一个必须完成的次数。鱼类脂肪与汞含量因品种而异，不把所有金枪鱼一概计为高脂鱼；不确定品种先核对。分类名「高脂深海鱼」沿用产品名称，不要求鱼必须生活在深海。

以上 3/5/4/5/3/2 是本工具的默认安排，不是研究证明的最低有效量。不同类别可由同一道菜覆盖，不用把所有次数换算成互斥菜位。

## 中性食物 1 项

海藻、普通蔬果、牛奶及植物奶、奶酪、干果、土豆/山药/芋头/莲藕、猪肉、蜂蜜等。

**中性只表示不增加本工具的目标覆盖，不代表没有营养或没有健康益处。** 土豆等完整薯类不等于精制谷物；燕麦奶不自动计为全谷、杏仁奶不自动计为坚果。猪肉在本产品中保留原来的存放位置，但营养分类上仍属于红肉，不应据此认为可以不受限制地食用。

## 限制项

只记录用户明确提到或成分足够明确的项目。不从菜名猜盐量、糖量或加工等级，不把所有罐头、冷冻食品和瓶装酱料统一判为超加工。

| key | 记录内容 |
|---|---|
| processedMeat | 加工肉 |
| sugaryDrink | 含糖饮料 |
| ultraProcessed | 经配料或用户描述确认的超加工食品 |
| transFat | 明确的反式脂肪或反复使用的煎炸油；沿用历史 key |
| refinedGrainMeal | 用户明确说以精制谷物为主且搭配单一的一餐 |
| deepFried | 油炸 |
| tooSalty | 用户说明偏咸 |
| alcohol | 酒精 |

普通液态植物油不属于反式脂肪。白米饭出现在一顿饭里不自动触发限制项。库存中的「加工品」是整理区，不自动转成日志中的限制项。只报次数，不评判。

## 计数规则与实现边界

- 同一食材可命中多类；小白菜、鸡毛菜、芥蓝、油菜同时命中深色绿叶菜和十字花科。
- 同餐同类取最大权重，上限 1；「花生酱 核桃」与「核桃 花生酱」结果相同。两个半份词在同餐不叠加成两次；跨餐可累计到每日 ≥1。
- 每周项跨餐累计，同一餐不重复。枸杞 + 番茄在同餐计红橙色蔬果 1 次。
- 日志使用食材词，不用整道菜名。脚本接受空格、逗号、顿号分隔及显式别名；未识别词出现在 `unrecognizedItems` 中，先核对再分析。
- 库存可从已知词匹配更长的商品名称，**不适合据此直接给成品菜打分**。未知库存单列待确认，不偷偷塞进中性食物。
- 一周固定显示 7 天；有实际餐次或限制项记录才计为有记录的一天。空日期标题和归档摘要不参与计算。
- 每日项显示 `覆盖天数/有记录天数`，每周项显示 `已记录次数/默认目标`。不据少数记录给整周贴「掉队」标签，未记录不等于没吃。
- 计划餐单只展示预计覆盖，不得写入实际摄入日志。

## 搭配提示

最多两条，优先实用口味与搭配：番茄配橄榄油；豆类配蔬菜和柑橘；味噌后放保留风味；香料帮助少盐调味。不把烹饪小技巧描述为治疗效果或保证吸收的条件。

## 依据与局限

- [AHA 2021 膳食指导](https://professional.heart.org/en/science-news/2021-dietary-guidance-to-improve-cardiovascular-health/top-things-to-know)：支持关注整体饮食模式，选择蔬果、全谷、健康蛋白和液态植物油。它并没有验证本工具的 19 类、半份权重或每周数字。
- [Wastyk 等，Cell 2021](https://doi.org/10.1016/j.cell.2021.06.019)：36 名健康成人的随机饮食干预，发酵食品组出现部分免疫和炎症指标变化。这不能证明每个人每天一份酸奶都有同等效果，更不能推出「多多益善」。
- [NHLBI：Following DASH](https://www.nhlbi.nih.gov/health/dash/following-dash)：提供均衡膳食的食物分组与份量示例，完整薯类列为蔬菜，不等于精制谷物。

不把多酚半衰期推导为「一天不吃就失效」，不声称仅四类食物有人体研究，不承诺降低个人炎症指标。需要临床营养建议时，应结合个人情况咨询合适的专业人员。
