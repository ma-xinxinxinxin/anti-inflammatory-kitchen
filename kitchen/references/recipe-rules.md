# 菜谱生成规则

## 两步走，不要一步到位

**第一步给候选**：2–3 个，每个只有菜名 + 一句理由。理由要说清三件事里的至少两件——补哪一类、多久、用到冰箱里的什么。

```
香煎鲭鱼配蒜香茼蒿    补高脂深海鱼和深色绿叶菜 · 25 分钟 · 用到现有的鲭鱼
味噌菌菇豆腐汤        补发酵食品和菌菇 · 15 分钟 · 用掉香菇和半盒豆腐
番茄炖鹰嘴豆卧蛋      补豆类与豆制品 · 20 分钟 · 一锅出，可按需要分装保存
```

**第二步才展开**：用户挑中后再写完整食材表和做法。

## 硬约束

1. **用户此刻想吃什么权重最高。** 他说想吃鱼就出鱼，不要因为"今天缺绿叶"改成炒青菜。缺口通过配菜补，不通过否决主菜。
2. **最多补 3 样需要额外买的东西。** 包括调味料在内，只把明确存在的库存当作已有；缺少基础调料时给可用替代。
3. **工作日 ≤25 分钟、≤2 个锅。** 问不出场景时默认工作日。周末和招待才放开。
4. **步骤要有技法信息量。** 用户做饭认真，别写"炒熟"。写：什么时候下锅、锅要多热、看到什么现象进下一步、为什么这么做。一句 why 比三句 what 有用。
5. **末尾列命中类别**，再加最多两条由这一餐真实成分触发的搭配提示。

## 地中海底盘的实际含义

不是"必须是意大利菜"，是结构：

- 脂肪来自橄榄油、坚果、鱼，优先用液态植物油替换部分黄油和猪油，不把精炼种子油一概视为有害
- 蛋白以鱼、豆类、禽类为主，红肉是配角
- 蔬菜占体积一半以上
- 酸和香草承担调味，不是糖和大量酱油
- 主食优先全谷或豆类，按食欲与个人需要搭配

按这个结构，蒜蓉橄榄油炒茼蒿 + 香煎鲭鱼 + 藜麦和一道正经地中海菜是同构的。**中式做法完全可以，不要为了"像地中海"硬塞罗勒和帕玛森。**

## 中餐抗炎化的三个开关

用户日常还是吃中餐。可用这三个烹饪方向：

1. **换油**——可用适合做法的橄榄油或其他液态植物油；避免持续冒烟和反复煎炸。
2. **加酸收尾**——起锅前一点柠檬汁或好醋，增加风味，减少依赖糖和盐。
3. **减钠补味**——酱油减半，用香草、蒜、柑橘皮、白胡椒补回来。

容易搭配的中餐：清蒸鱼、白灼绿叶菜、凉拌木耳、蒜蓉西兰花、番茄炖菜、香菇焖鸡、紫菜蛋花汤。

## 几个可变形复用的模板

- **一盘烤**：蔬菜 + 蛋白 + EVOO + 香料 → 约 200°C 烤制，时间按食材厚度和实际熟度调整。最省事，覆盖度高。
- **番茄炖豆**：橄榄油炒香蒜和香料 → 番茄 → 豆类罐头 → 收汁 → 卧蛋或摆鱼。一锅出，可按需要分装保存。
- **谷物碗**：藜麦/糙米打底 + 生熟蔬菜各一 + 蛋白 + 坚果 + 柠檬 EVOO 汁。适合带饭。
- **快煎鱼**：厚底锅烧热、鱼皮拍干、皮朝下煎定型后翻面，按厚度调整时间并确认中心熟透。配柠檬蒜末 EVOO。

## 招待朋友

- 3–4 道 + 一个能提前做的主菜
- **标出哪些步骤可以前一天做完**，提前量比菜本身重要
- 不要因为"抗炎"把菜做寡淡。紫甘蓝、石榴、橄榄、迷迭香颜色和味道都强，是加分项不是妥协

## 清库菜谱（第 7 件事专用）

- 按常识排易坏程度：绿叶菜 → 菌菇/鱼 → 根茎 → 罐头油米茶。库存里不存日期，拿不准就问用户一句「哪样快坏了」
- 围绕最急的两三样出菜，**允许这一顿 8 类不齐**，但要说清楚："这顿主要是把茼蒿和豆腐吃掉，深色绿叶菜和豆类与豆制品有覆盖，浆果柑橘和坚果种子可在其他餐考虑。"
- 宁可出一道能一次吃掉两样将坏食材的菜，也不要出三道各用一点的
