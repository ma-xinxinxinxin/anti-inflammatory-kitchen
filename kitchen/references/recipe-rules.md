# 菜谱生成规则

## 两步走，不要一步到位

**第一步给候选**：2–3 个，每个只有菜名 + 一句理由。理由要说清三件事里的至少两件——补哪一类、多久、用到冰箱里的什么。

```
香煎鲭鱼配蒜香茼蒿    补深海鱼和绿叶 · 25 分钟 · 鲭鱼再放两天就该扔了
味噌菌菇豆腐汤        补发酵和菌菇 · 15 分钟 · 用掉香菇和半盒豆腐
番茄炖鹰嘴豆卧蛋      补豆类 · 20 分钟 · 一锅出，冷藏三天更好吃
```

**第二步才展开**：用户挑中后再写完整食材表和做法。

## 硬约束

1. **用户此刻想吃什么权重最高。** 他说想吃鱼就出鱼，不要因为"今天缺绿叶"改成炒青菜。缺口通过配菜补，不通过否决主菜。
2. **最多补 3 样需要额外买的东西。** 不计入这 3 样（默认厨房有）：橄榄油、盐、黑胡椒、柠檬、蒜、洋葱、常用干香料、醋。
3. **工作日 ≤25 分钟、≤2 个锅。** 问不出场景时默认工作日。周末和招待才放开。
4. **步骤要有技法信息量。** 用户做饭认真，别写"炒熟"。写：什么时候下锅、锅要多热、看到什么现象进下一步、为什么这么做。一句 why 比三句 what 有用。
5. **末尾列命中类别**，再加最多两条由这一餐真实成分触发的搭配提示。

## 地中海底盘的实际含义

不是"必须是意大利菜"，是结构：

- 脂肪来自橄榄油、坚果、鱼，不是黄油、猪油、精炼种子油
- 蛋白以鱼、豆类、禽类为主，红肉是配角
- 蔬菜占体积一半以上
- 酸和香草承担调味，不是糖和大量酱油
- 主食是全谷或豆类，量克制

按这个结构，蒜蓉橄榄油炒茼蒿 + 香煎鲭鱼 + 藜麦和一道正经地中海菜是同构的。**中式做法完全可以，不要为了"像地中海"硬塞罗勒和帕玛森。**

## 中餐抗炎化的三个开关

用户日常还是吃中餐。这三件事拿到大部分收益：

1. **换油**——炒菜用 EVOO 或山茶油。家用灶实际很难超过 EVOO 烟点（190–210°C），日常炒菜完全可用。
2. **加酸收尾**——起锅前一点柠檬汁或好醋，替代糖提鲜，同时压餐后血糖。
3. **减钠补味**——酱油减半，用香草、蒜、柑橘皮、白胡椒补回来。

天然高分中餐：清蒸鱼、白灼绿叶菜、凉拌木耳、蒜蓉西兰花、番茄炖菜、香菇焖鸡、紫菜蛋花汤。

## 几个可变形复用的模板

- **一盘烤**：蔬菜 + 蛋白 + EVOO + 香料 → 200°C 20 分钟。最省事，覆盖度高。
- **番茄炖豆**：橄榄油炒香蒜和香料 → 番茄 → 豆类罐头 → 收汁 → 卧蛋或摆鱼。一锅出，冷藏三天更好吃。
- **谷物碗**：藜麦/糙米打底 + 生熟蔬菜各一 + 蛋白 + 坚果 + 柠檬 EVOO 汁。适合带饭。
- **快煎鱼**：厚底锅烧热、鱼皮拍干、皮朝下压 4 分钟不动、翻面 1 分钟离火。配柠檬蒜末 EVOO。

## 招待朋友

- 3–4 道 + 一个能提前做的主菜
- **标出哪些步骤可以前一天做完**，提前量比菜本身重要
- 不要因为"抗炎"把菜做寡淡。紫甘蓝、石榴、橄榄、迷迭香颜色和味道都强，是加分项不是妥协

## 清库菜谱（第 7 件事专用）

- 按常识排易坏程度：绿叶菜 → 菌菇/鱼 → 根茎 → 罐头油米茶。库存里不存日期，拿不准就问用户一句「哪样快坏了」
- 围绕最急的两三样出菜，**允许这一顿 8 类不齐**，但要说清楚："这顿主要是把茼蒿和豆腐吃掉，绿叶和豆制品到位，浆果和坚果今天得靠加餐补。"
- 宁可出一道能一次吃掉两样将坏食材的菜，也不要出三道各用一点的
