# 视觉规范

两个场景默认渲染成视觉：**今日餐单与营养**、**周复盘**。其余操作用文字。

## 怎么渲染

**有代码环境**（推荐）：
```bash
python3 scripts/kitchen.py score --log kitchen-log.md --end 2026-09-07 > week.json
# 把 review 三段文字合并进 week.json 后
python3 scripts/kitchen.py week --json week.json -o review.html
python3 scripts/kitchen.py day  --json day.json  -o today.html
```
字段说明跑 `python3 scripts/kitchen.py schema`。渲染完用环境实际可用的文件预览或附件工具交给用户；本地环境可提供 HTML 文件链接。不要假设 `present_files` 一定存在。

**没有代码环境但有视觉工具**：用实际可用的视觉工具手写 HTML，严格按下面的 token。**打分仍然要按 food-table.md 的口径手算，不能凭印象。**

有个人频次时，周卡读取 `score` 输出的 `personalPlan`，展示实际频次与记录；不使用默认每日矩阵评判。今日餐单可用 Markdown 的「类别 | 个人频次 | 今日/本周记录 | 库存建议」表，或按相同数据渲染，不调用仅适用于默认 8 类的 `day` 圆环。

## 字体

- 中文与全局：`Noto Sans SC` 300/400/500/700
- 数字与英文：`Space Grotesk` 400/500/700（覆盖数、次数、日期、时间）

| 角色 | 规格 |
|---|---|
| 屏幕主标题 | 700 / 21–24px / lh 1.35 |
| 区块标题 | 500 / 12.5–13px |
| 卡片主文字 | 500 / 13.5–15px |
| 正文 | 400 / 12.5–13px / lh 1.7–1.85 |
| 次级说明 | 400 / 11–11.5px / lh 1.6 |
| pill | 400 / 11–12.5px |
| 大数字 | Space Grotesk 700 / 15–26px |

间距刻度 `4 5 6 7 8 9 11 13 14 16 18 22 26`，左右内边距手机 22px。
圆角：pill 11–14 / 卡片 14–20 / 面板 18–22 / 按钮 22–24 / 图片 14–18。
布局一律 flex/grid + gap，不用 margin 拼间距。

## 两个视觉都是一整页长图，不是分屏

**今天**（`kitchen.py day`）和 **复盘**（`kitchen.py week`）各自是一张从上滚到底的长页，中间用 1px hairline 分节，**没有返回链接、没有跳转**。

### 今天（上半：今天的餐单 / 下半：今日抗炎营养）

上半：日期 + 标题 + 34px 头像 → 6 格周条（当天绿底）→ 绿色覆盖卡（74px 进度环 + 类别覆盖数（如 6/8） + 「每日必有 6/8 · 缺深色绿叶菜、茶饮」）→ 四个餐位卡（48px 占位图 + 「早餐 · 08:00」+ 菜名 + 右侧「N 类」；踩限制项的餐右侧改显 clay 标记如「偏咸」；空位虚线 +「还空着」+ 箭头）

hairline

下半：标题「今日抗炎营养」+ 右上 `n / 8 类` → 8 格 2 列（到位绿底，**右侧写填上它的食材**如「鸡毛菜」「燕麦 · 糙米」「绿茶 2」；缺的虚线 + clay「缺 ›」）→ 说明行（要点名冰箱里现成的）→ 每周达标 6 项（`n/t` 数字，达标绿底 / 落后 clay 底 / 其余灰底）→ 其他优质蛋白「今天吃到的」· 其他中性食物「不算格子」（olive pill）→ 限制项「今天踩中的」（clay pill）

### 复盘（上半：复盘矩阵 / 下半：这周怎么样）

上半：标题「复盘」→ 日期范围（绿色胶囊「9月1日 – 9月7日」）→ 一句「7 天里有 5 天记录，按记了的算」→ **每日必有 8 类 · 达标天数**：每行 = 类别名（82px）+ 7 个圆角方块（高 24px，radius 7，`flex:1`）+ 右侧 `met/logged`
- 方块三态：达标 = 实心 green｜有记录未达标 = 实心 `#E4E1D2`｜没记录 = `1px dashed rgba(42,42,36,.3)`
- 右侧数字：有记录且全部记录日覆盖为 green，其余 ink；无记录用 muted。不把一天记录推断为整周表现。

## 只显示吃到的

其他蛋白、中性食物、限制项**只显示当天或当周真实吃到/踩中的**。一项都没有时显示灰底的「今天未记录到」「今天未记录到限制项」，**不要显示 0**。

个人频次表是目标与统计的对照，可以显示 0 次或尚无记录；上面的“只显示吃到的”规则适用于餐食展示的 pill，不要求隐藏用户设定的目标。

## 明确不要做

绿色系健康 app 观感、圆环之外的图表、大号百分比分数、SaaS 套件式的统一阴影卡片、全大写标签、emoji、"太棒了"、成就徽章、连续打卡天数、体重目标、卡路里。

## 能力与数据约束

没有视觉工具时用同结构的 Markdown 表并说明限制。HTML 是可离线打开的静态文件，使用系统字体回退；不添加日期切换或重新生成等假按钮。所有输入文案使用纯文本，渲染器会转义 HTML。圆环从八类 daily 数据计算，计划卡必须注明计划；实际记录和预测不能混算。
